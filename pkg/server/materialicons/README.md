# Material Design fitness icons

These are unmodified, 24-pixel **rounded** SVGs from Google's
[Material Design Icons](https://github.com/google/material-design-icons),
revision `49d4db35df873165d6bd6ba09b063c7dafbac2f4`.

They are distributed under the **Apache License 2.0**; the upstream licence
is included in [LICENSE](LICENSE). Google supplies the original artwork.
Perkeep embeds and rasterizes the paths locally; no icon-service requests or
external fonts are needed.

| --- | --- |
| `run` | `maps/directions_run/materialiconsround/24px.svg` |
| `walk` | `maps/directions_walk/materialiconsround/24px.svg` |
| `hike` | `social/hiking/materialiconsround/24px.svg` |
| `ride` | `maps/directions_bike/materialiconsround/24px.svg` |
| `swim` | `places/pool/materialiconsround/24px.svg` |
| `row` | `action/rowing/materialiconsround/24px.svg` |
| `ski` | `social/downhill_skiing/materialiconsround/24px.svg` |
| `workout` | `places/fitness_center/materialiconsround/24px.svg` |
| `other` | `social/sports/materialiconsround/24px.svg` |

The local files are named after their upstream icons. Updates should preserve
these original SVGs and record the new upstream revision here. Bump the fitness
thumbnail rendering version whenever the badge artwork changes.
